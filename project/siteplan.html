1. Site Name

AB7ec — pronounced "ABTec". The numeric character 7 visually represents a t, giving the brand a technical feel while keeping the name short and memorable.

Suggested domain (optional): ab7ec.com (domain availability not verified here).

2. Site Purpose

The website provides clear information about computer repair and technical services: diagnostics, hardware repair, component upgrades, OS installation, data recovery, virus/malware removal, networking support, and maintenance plans. The site also includes a dedicated technician section with practical guides and reference materials.

Technician section: A set of practical guides and checklists for technicians (e.g., POST failure diagnostics, SSD replacement procedures, secure data recovery steps, maintenance checklists). Initially public, with the option to gate advanced content later.

3. Scenarios

  • Customer: "My laptop is very slow. What service should I request and what will it cost?"
  • Customer: "I have a drive that won't boot. Can you recover my files?"
  • Technician: "Where can I find the SSD replacement guide for common laptop models?"
  • Customer: "What are your hours, and how do I book an appointment?"

  • Bright Tech Blue — #006BBD (primary CTAs, links, highlights)

5. Typography

Selected fonts (2):

  • Montserrat — used for headings (H1, H2) and the logo to convey a strong, modern brand presence.
  • Roboto — used for body text, lists, and longer content for excellent readability on screens.

This document uses both fonts (see header and body), satisfying the typography use requirement.
