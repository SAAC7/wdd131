1. Site Name

AB7ec — (se pronuncia "ABTec"; el dígito 7 representa la letra t). El nombre es corto, memorable y comunica la naturaleza técnica del servicio.

Optional domain: ab7ec.com (disponibilidad no verificada en esta entrega).

2. Site Purpose

El sitio proporcionará información y contacto para servicios de diagnóstico, reparación de hardware, mantenimiento preventivo, instalación/actualización de sistemas operativos, recuperación de datos y optimización del rendimiento. Además, incluirá una sección técnica interna con guías y tutoriales para técnicos.

Sección para técnicos: Área con guías prácticas (ej. diagnóstico de fallas, reemplazo de SSD, recuperación de datos, limpieza de sistemas, procedimientos de seguridad y checklist de verificación). Esta sección será de acceso público inicialmente, con opción de futuras páginas protegidas.

3. Scenarios

  • Cliente: "Mi laptop está muy lenta, ¿qué servicio necesito y cuánto costará?"
  • Cliente: "¿Pueden recuperar archivos de un disco que no arranca?"
  • Técnico: "¿Dónde encuentro la guía para reemplazar la unidad SSD en modelos comunes?"
  • Cliente: "¿Cuál es el horario y cómo puedo agendar una cita?"

4. Color Schema

He definido cuatro colores principales para mantener coherencia visual en todo el sitio:

  • Primario oscuro — #1D2025 (Encabezados, hero background, y elementos de marca).
  • Gris técnico — #56616E (Fondos secundarios, bordes, texto secundario).
  • Azul profesional — #006BBD (Botones principales, enlaces, CTA).
  • Azul profundo — #003165 (Acentos secundarios, hover states, iconografía).

5. Typography

Fuentes seleccionadas (2):

  • Montserrat — Usada para encabezados (h1, h2) y logotipo para transmitir solidez y legibilidad en títulos.
  • Roboto — Usada para el cuerpo de texto, listas, formularios y contenido técnico por su legibilidad en pantalla.

Se aplican en este documento (ver encabezados y cuerpo) para cumplir el criterio de la rúbrica.

8. Testing

Auto-evaluación y herramientas a utilizar:

  • HTML validator: W3C Nu Validator — corregir errores reportados.
  • CSS validator: W3C CSS Validator.
  • Accesibilidad: Lighthouse / WAVE para revisar contrastes y etiquetas ARIA si es necesario.
  • Performance / SEO: Lighthouse y PageSpeed para recomendaciones (imágenes optimizadas, lazy-loading, meta tags).

Notas rápidas:

  • Contraste: usar `#006BBD` sobre blanco para CTAs (suficiente), y `#003165` para hover states.
  • Imágenes: usar tamaños responsive y `loading="lazy"` en galerías o listas.
